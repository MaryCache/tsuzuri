# 論文（LaTeX）

学術論文や研究レポートを LaTeX で執筆・レビューする文章に使用します。

## 文章の形の既定

要件定義書の「9. 文章の形」には次を既定として記述し、依頼や投稿先の規定に合わせて修正してください。

- 種類: 学術論文・研究レポート（学会誌・研究会・卒業論文など、依頼から決定します）
- 長さ: 投稿先のページ上限や文字数規定に合わせます（指定が無ければA4で4〜8ページほど）
- 媒体: LaTeX 原稿（`export --flavor latex` で `text.tex` を書き出します）
- 文体: 文語の常体（だ・である）。読点は「，」、句点は「．」で統一します（投稿先の指定が「、」「。」ならそちらに合わせます）

## 骨組み

見出しはブロックで記録し（レベル1〜4が順に `\section`・`\subsection`・`\subsubsection`・`\paragraph`）、材料に無い節は外してください。
プリアンブルは `meta`、コメント行は `comment`、数式は `math`、図表は `image`・`table`、`\label` などの密着記述は `raw`（`"attach": true`）で記録します。

```tex
% meta（必要に応じてプリアンブルや \title・\author・\begin{document} を登録）

\section{はじめに}
\label{sec:intro}
% 根拠: 研究背景と解決したい課題の出典メモ
<背景と未解決の課題を一文ずつ記述>
<本稿の提案と貢献を明確に示す>

\section{関連研究}
\label{sec:related}
<既存手法の分類と、本稿の課題に対する限界>

\section{提案手法}
\label{sec:method}
<手法の全体像と設計の根拠>
% 数式は math ブロック、図表は image・table ブロックで記録

\section{評価実験}
\label{sec:eval}
\subsection{実験設定}
<データセット・比較対象・評価指標・再現条件>
\subsection{実験結果}
<結果の事実と数値（解釈と混ぜない）>

\section{考察}
\label{sec:discussion}
<結果から言えること、提案手法の限界と妥当性の脅威>

\section{おわりに}
\label{sec:conclusion}
<結論の要約と今後の課題>
```

## 段落の並びの考え方

- 「はじめに」では、広い背景を長く語らず、未解決の課題と本稿の貢献を冒頭の数段落で明示します。
- 「関連研究」では、先行研究を並べるだけで終わらせず、本稿が解く課題に対して何が足りないかを対比して示します。
- 「実験結果」には測定した事実と数値だけを記述し、原因の解釈や限界の議論は「考察」へ分けて主張の飛躍を防ぎます。
- 出典や計算根拠のメモは `comment` ブロックで該当する文の直前に置き、段落を切らずに推敲時の検証材料として残します。

## 確認項目

- 句読点の統一: 全文で「，」「．」（または投稿先指定の「、」「。」）が混在していないか確認する
- 参照と引用の整合: 本文中の `\ref`・`\eqref`・`\cite` に対応するラベルや文献があり、本文から言及されていない図表が残っていないか確認する
- 事実と解釈の分離: 実験結果の節に根拠のない推測が混ざっていないか、限界や前提条件が考察に明記されているか確認する
